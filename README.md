# Employee Reporting System

Struktur project untuk live demo employee reporting system.

## Struktur

- `projects/employee-reporting-system/index.html` — halaman aplikasi utama
- `script.js` — JavaScript frontend / UI behavior
- `style.css` — CSS frontend
- `infrastructure/demo-backend.js` — adapter backend demo berbasis browser storage
- `assets/images/` — aset gambar
- `assets/files/` — aset file

## Menjalankan

Buka `projects/employee-reporting-system/index.html` melalui browser atau static server.

> Backend pada versi ini tetap merupakan backend demo yang berjalan di browser. Pemisahan folder hanya merapikan struktur project dan tidak mengubah fitur/tampilan aplikasi.
