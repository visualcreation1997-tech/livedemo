# Deployment

Project ini dapat dideploy sebagai static site karena live demo saat ini menyimpan data demo di browser.

Entry point:
`projects/employee-reporting-system/index.html`

Untuk deployment static hosting, pastikan seluruh folder project diunggah sehingga path relatif berikut tetap tersedia:

- `../../style.css`
- `../../script.js`
- `../../infrastructure/demo-backend.js`
